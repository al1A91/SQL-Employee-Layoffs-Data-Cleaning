# SQL Employee Layoffs Data Cleaning

## Project Overview
This project involves cleaning and transforming employee layoffs data. The goal is to preprocess the raw data, handle duplicates, standardize values, and ensure the dataset is ready for analysis.

## Files in this repository

- **Data_Cleaning.sql**: SQL script used for cleaning the layoffs data.
- **Explotary_Data_Analysis.sql**: SQL queries for exploratory data analysis.
- **layoffs.csv**: Raw layoffs data (initially in CSV format).
- **LICENSE**: The license under which the project is distributed.
- **.gitignore**: Lists files and directories that should be ignored by Git.
